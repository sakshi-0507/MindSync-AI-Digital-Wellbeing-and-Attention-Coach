# 🧠 MindSync AI
### Your Personalized Digital Wellbeing and Attention Coach

MindSync AI is a machine learning-based application that analyzes digital habits and predicts digital wellbeing risk levels using a trained Random Forest model.

## Features
- Digital wellbeing risk prediction
- Smartphone and social media usage analysis
- Personalized habit-improvement recommendations
- Digital attention and screen-time awareness

## Tech Stack
- Python
- Pandas & NumPy
- Scikit-learn
- Random Forest
- Streamlit

## Objective
To encourage healthier digital habits through data-driven insights and personalized recommendations.

## Disclaimer
MindSync AI is an educational wellbeing tool, not a medical diagnostic system.
